# Skill — Osservazione visiva FO statico

Attivazione: incarichi di osservazione preliminare di UN singolo asset Food Object MealUp.
Il file fornito è UNA sola immagine statica WebP con trasparenza possibile. Se il visualizzatore mostra bianco, non dedurre che il file abbia uno sfondo bianco.
Descrivi esclusivamente ciò che si vede nei pixel: forma, colore, disposizione e texture. Le sequenze di frame, altre card, altri crop, interazioni o dimensioni non sono stati forniti.
Usa la famiglia food solo se coerente con il visibile. Se incerto, metti il punto nel campo uncertainties e non inventare.
La Skill non certifica FROZEN, produzione o rendering su iPhone.
